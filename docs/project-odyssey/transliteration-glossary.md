# 奥德赛 Wiki 中英音译对照表（Transliteration Glossary）

> 本文档是 content/odyssey 中文内容译名的唯一标准。写中文词条前先查本表；本表没有的名字，按「音译规则速记」推导并在本表登记后再使用。

## 使用规则（必读）

1. **主译名**：正文一律使用本表「主译名」列。首次出现写「中文（English）」格式，此后只用中文。
2. **变体**：表内「别名/变体」列中的译名只允许出现在 frontmatter 的 `aliases` 字段（用于搜索与自动链接），不用于正文。
3. **依据**：主译名以 wiki 现有内容的多数用法为准（大致为罗念生/陈中梅风格）；中文引文参照王焕生译《奥德赛》（人民文学出版社）——引文用词与译名体系不必一致。
4. **希腊文**：只在词条标题与 CharacterCard 的 `greekName` 中出现。
5. **出现不一致时**：以本表为准；发现新不一致请更新「已知不一致清单」并顺手统一。

## 音译规则速记（表中没有的名字）

- 阳性名词词尾 **-os / -us**：多译「俄斯」「奥斯」「托斯」「洛斯」（如 Antinous→安提诺俄斯，Peisistratus→佩西斯特拉托斯，Nestor→涅斯托尔）
- **-eus**：多译「修斯」（Odysseus→奥德修斯）或「透斯」（Proteus→普罗透斯）
- 女性名：珀涅罗珀、卡吕普索、喀耳刻、欧律克勒娅一类为主流约定，查表优先
- 神名有固定译法（见下表），不可自创
- 拟好译名后**必须**登记到本表，并把变体补进相应词条的 aliases
