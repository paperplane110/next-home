# AI 腔调黑名单（AI Flavor Blacklist）

> 记录 AI 味很重的句式与词汇。写 Odyssey Wiki 中英正文前先查本表；本文档由人与 AI 双向维护——发现任何一条 AI 腔调的漏网之鱼，随手记进来。

## 使用规则

1. 写正文时避开「黑名单」中的表达；同类句式（哪怕不在表里）也一律警惕。
2. 本表是**下限**，不是充分条件：没有黑名单词 ≠ 没有 AI 味。
3. 看到可疑表达就补充进对应分区，格式：`表达 | 问题 | 替代写法（可选）`。
4. 新增内容应同时检查 zh 与 en 两版正文。

## 写作原则（先于黑名单）

- 段落结尾**不要逐段升华**：直接收在事实、引文或具体判断上；「而这，正是……」式的收尾每篇最多一次。
- 减少排比；确有排比时，用长短句打破匀速节奏。
- 避免「万能动词」（彰显 / 诠释 / 见证 / 谱写 / 凸显），换成具体、有信息量的动词。
- 少用导游腔（「我们不难发现」「让我们把目光投向」），让内容直接说话。
- 具体细节与引文优先于形容词；形容词堆叠是 AI 味的最大来源。
- 中文正文排查翻译腔：「进行了……」「对于……来说」这类结构尽量改写。
- 尽量少的使用带破折号“——”的句式，因为正常中文文章中会将过长的从句拆散为小句。

## 中文黑名单

| 表达 | 问题 | 替代写法 |
| --- | --- | --- |
| 值得注意的是 / 值得一提的是 | 万能插入语，无信息量 | 直接删掉，或说清「注意什么」 |
| 综上所述 / 总而言之 / 归根结底 | 总结腔，滥用 | 删；必要时用具体一句收束 |
| 不难发现 / 不难看出 / 由此可见 | 导游腔 | 直接陈述结论 |
| 令人深思 / 引人深思 / 发人深省 | 廉价升华 | 删；让事实自己说话 |
| 深刻地揭示了 / 生动地诠释了 | 评价词堆叠 | 换成具体动词 |
| 充分体现 / 充分彰显 / 完美诠释 | 空洞强化 | 说具体体现为哪件事 |
| 见证了 | 拟人腔滥用 | 直接陈述事件 |
| 为……注入了新的活力 / 内涵 | 万能补语 | 具体写「带来/改变了什么」 |
| 在……的宏大叙事中 | 空泛框架词 | 删 |
| 从某种意义上说 / 在某种意义上 | 自我消解式限定 | 删；或给出明确限定 |
| 而这，正是…… | 每段结尾升华句式 | 最多用一次，最好不用 |
| 不仅……更是…… | 强行递进 | 拆成两句 |
| 宛如一幅画卷 / 徐徐展开 | 比喻套路 | 删或换成具体比喻 |
| 大放异彩 / 熠熠生辉 | 成语空转 | 具体描述 |
| 环环相扣 / 层层递进 | 评论腔 | 具体写结构关系 |
| 我们不难发现 | 导游腔 | 删主语，直接陈述 |
| 让我们把目光投向 | 导游腔 | 删 |
| 底层逻辑 | 词汇太ai | 删 |
| 底层代码 | 词汇太ai | 删 |


## 英文黑名单

| 表达 | 问题 | 替代写法 |
| --- | --- | --- |
| It's worth noting that / It is important to note | 万能插入语 | 删；或直接陈述 |
| Moreover / Furthermore / Additionally | 高频连用 | 多数直接删，用句序承接 |
| In conclusion / To sum up / All in all | 总结腔 | 删 |
| delve into / dive into | 流行腔 | 用 examine / look at / 具体动词 |
| a rich tapestry / intricate tapestry | 比喻套路 | 删或换成具体比喻 |
| testament to | 万能评价 | 换成具体事实 |
| showcase / underscores / highlights | 高频万能动词 | 换成具体动词 |
| embark on a journey | 隐喻滥用 | 用 begin / set out |
| plays a crucial / pivotal / vital role | 空洞强调 | 说具体作用 |
| arguably / undoubtedly | 模糊限定滥用 | 删；或给出明确论证 |
| seamlessly / effortlessly / beautifully crafted | 形容词堆叠 | 删 |
| reminds us that | 导游腔 | 直接陈述 |
| shed light on | 万能动词 | 换成具体动词 |
| not only... but also... | 堆叠递进 | 拆句 |
| a fascinating / compelling look at | 评论腔 | 删 |
